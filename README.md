# Endless Run

Низкополигональный бесконечный раннер на Three.js. Мяч катится по треку, висящему в небе:
уходи от блоков, перепрыгивай пропасти, собирай кристаллы и держи множитель комбо.

Игра целиком в одном файле — `index.html`. Сборка не требуется.

## Играть

- **GitHub Pages (обновляется автоматически):** https://bjpfv12-ui.github.io/endless-run/
- **Зеркало на mcode-хостинге:** https://9xje5u3vg1w87.space.mcode.io

## Управление

| Действие | Клавиши |
|---|---|
| Сменить полосу | `A` / `D` или `←` / `→` |
| Прыжок (удерживай — выше) | `Space` или `↑` |
| Быстрое падение в воздухе | `↓` или `S` |
| Пауза | `Esc` или `P` |
| Перезапуск | `R` |

На тачскрине: свайп влево/вправо — смена полосы, вверх — прыжок, вниз — dive.

## Настройки

Кнопка Settings в меню и в паузе: громкость музыки и звуков, кнопки mute. Значения
сохраняются в `localStorage` и применяются сразу.

## Автодеплой

`.github/workflows/deploy.yml` на каждый пуш в `main` собирает статику и публикует её
через `actions/deploy-pages`. Сборка — это просто копирование `index.html` в `_site`.
Первый запуск сам включает Pages для репозитория (`actions/configure-pages`).

Проверить статус: https://github.com/bjpfv12-ui/endless-run/actions

## Запуск локально

Открой `index.html` в браузере или подними статический сервер:

```bash
python -m http.server 8777
```

Three.js подключается с unpkg, поэтому нужен интернет.
